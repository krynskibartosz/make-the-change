# Thumbnail Generation Workflow

1. Open the ChatGPT project/folder with the global thumbnail instructions installed.
2. Start one chat per missing species if running generation in parallel.
3. Paste the prompt from the matching `species/thumbnail-*.md` file.
4. Generate exactly one square image.
5. Validate the result before saving.
6. If rejected, revise only the species-specific line or the context line; keep the global thumbnail style stable.
7. Save the approved file using the exact target filename from the prompt.

## Validation Checklist

Biology:

- Species is recognizable in one second.
- Key markings, shape, color, and habitat are plausible.
- No confusing lookalike species.
- No invented anatomy.

Thumbnail UI:

- Square crop works.
- Subject remains readable at 80x80 px.
- Subject is not too small.
- Background is simple and soft.
- No secondary subject competes.

Style:

- Ultra-realistic wildlife photography.
- Premium, sober, natural color grade.
- No fantasy or illustration.
