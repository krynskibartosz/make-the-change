# Generation Workflow

1. Open the ChatGPT project/folder with the global instructions installed.
2. Start one chat per species if running generation in parallel.
3. Paste the prompt from the matching `species/hero-*.md` file.
4. Generate exactly one vertical mobile-first image.
5. Validate the result before saving.
6. If rejected, revise only the species-specific line or the context line; keep the global style stable.
7. Save the approved file using the exact target filename from the prompt.

## Validation Checklist

Biology:

- Species is recognizable in one second.
- Key markings, shape, color, and habitat are plausible.
- No confusing lookalike species.
- No invented anatomy.

UI:

- Portrait composition works on mobile.
- Main subject is in the upper or central area.
- Lower third stays calm enough for title and overlay.
- No important feature is hidden where the app gradient/text will sit.

Style:

- Ultra-realistic wildlife photography.
- Premium, sober, natural color grade.
- Biome-specific light is respected.
- Context is useful but secondary.
