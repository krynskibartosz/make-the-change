# Contexte AI — Make the Change

Ce dossier contient 10 documents distillés, conçus pour être injectés comme contexte dans n'importe quel assistant IA (ChatGPT, Claude, Gemini, Grok, etc.).

## À qui s'adresse ce dossier

À toute IA qui travaille sur Make the Change : rédaction, décisions produit, réponses aux questions des utilisateurs, conception UX, business, impact, gamification.

## Règle fondamentale pour toute IA qui lit ces documents

Distinguer systématiquement :
- Ce qui est **validé** (décision assumée, règle en vigueur)
- Ce qui est une **hypothèse** (piste plausible, non testée)
- Ce qui est **interdit** (explicitement exclu en V1)
- Ce qui est **non décidé** (arbitrage ouvert)

Ne jamais présenter une hypothèse comme une décision. Ne jamais inventer une règle qui n'est pas dans ces documents.
