# Make the Change — Synthèse stratégique des décisions business

## Conclusion courte

[HYPOTHESE] Make the Change devrait être pensé comme une plateforme européenne à impact, pas comme une simple application de dons ni comme une marketplace classique.

La meilleure direction recommandée est :

* démarrer avec une structure claire, probablement une SRL ;
* garder une mission d’impact forte ;
* séparer strictement don pur, soutien producteur et achat produit ;
* éviter les promesses d’impact trop fortes ;
* utiliser un prestataire de paiement adapté aux plateformes ;
* limiter la boutique au départ ;
* ne pas gérer de stock interne en V1 ;
* retirer ou repousser les Graines si elles brouillent la compréhension ;
* garder les Credits Impact uniquement liés au soutien producteur.

## Décisions V1 à figer avant développement

[RECOMMANDÉ] Pour éviter que le produit parte dans plusieurs directions à la fois, les décisions suivantes doivent être considérées comme la doctrine V1 tant qu’un comptable, un juriste ou un PSP ne les invalide pas explicitement.

| Sujet | Décision V1 recommandée | Pourquoi c’est important |
| --- | --- | --- |
| Structure | SRL Make the Change pour la V1 | Plus adaptée aux commissions, services partenaires, paiements et ambition européenne. |
| Don / contribution | Utiliser “contribution au projet” par défaut | Réduit le risque de confusion avec un don fiscalement déductible. |
| Soutien producteur | Cœur économique V1 | C’est le flux le plus lisible pour générer revenus MTC + Credits Impact. |
| Produits | Partenaire vendeur officiel | Limite TVA, responsabilité produit, retours, stock et SAV côté MTC. |
| Credits Impact | Valeur d’usage interne uniquement | Évite de créer une monnaie, un avoir financier ou une promesse de remboursement. |
| Graines | Retirer de la V1 publique | Simplifie la compréhension utilisateur et évite la confusion avec les Credits Impact. |
| Preuve d’impact | Ne jamais assimiler paiement et impact mesuré | Protège la confiance et réduit le risque de greenwashing. |
| Paiements | PSP plateforme + ledger interne | Rend chaque euro traçable et sépare revenus MTC / argent partenaire. |

## Lexique public V1

[RECOMMANDÉ] Le vocabulaire public doit être verrouillé tôt dans le produit, les reçus, les emails, les dashboards et les CGU.

À privilégier :

* contribution au projet ;
* soutien producteur ;
* avantage partenaire ;
* suivi terrain ;
* nouvelle partenaire ;
* impact estimé ;
* donnée documentée ;
* Credits Impact utilisables dans Make the Change.

À éviter :

* investissement ;
* rendement ;
* retour financier ;
* part de projet ;
* don fiscal sauf validation spécifique ;
* impact garanti ;
* compensation ;
* monnaie ;
* crédit remboursable.

## 1. Ce qui est déjà validé

[VALIDÉ] Make the Change est une expérience mobile-first qui aide les utilisateurs à comprendre, soutenir et suivre des actions concrètes pour le vivant.

[VALIDÉ] Les projets terrain sont le cœur moral du produit.

[VALIDÉ] La boutique et les avantages sont des prolongements, pas le cœur de l’expérience.

[VALIDÉ] Il faut distinguer clairement :

* don pur ;
* soutien producteur ;
* achat produit ;
* apprentissage ;
* récompense ;
* suivi terrain ;
* preuve d’impact.

[VALIDÉ] Les Credits Impact viennent uniquement du soutien producteur.

[VALIDÉ] Un don pur ne donne pas de Credits Impact.

[VALIDÉ] Un achat produit ne crée pas de Credits Impact.

[VALIDÉ] Une mission, un défi ou un quiz Academy ne donnent pas de Credits Impact.

[VALIDÉ] Un paiement confirmé n’est pas une preuve d’impact mesuré.

[VALIDÉ] Il faut éviter le vocabulaire d’investissement financier : rendement, ROI, profit, part, remboursement garanti, impact garanti.

---

## 2. Décision recommandée pour le positionnement

[HYPOTHESE] Make the Change devrait être positionné comme :

> Une plateforme mobile qui permet de soutenir des projets biodiversité concrets, de comprendre les gestes réalisés, de suivre les nouvelles du terrain et d’accéder à des avantages responsables liés aux partenaires.

À éviter :

* plateforme d’investissement ;
* marketplace classique ;
* application de dons fiscaux ;
* jeu de points déconnecté du réel ;
* outil RSE complet dès la V1.

---

## 3. Décision recommandée pour la V1

[HYPOTHESE] Pour la V1, il vaut mieux faire simple, crédible et contrôlé.

Recommandation :

* 3 à 5 projets maximum ;
* peu de partenaires ;
* peu de produits ;
* pas de stock interne ;
* pas de marketplace ouverte ;
* suivi terrain simple mais régulier ;
* frais transparents ;
* dashboard admin minimal ;
* dashboard partenaire minimal ou reporting manuel structuré ;
* paiement via PSP de plateforme ;
* ledger interne obligatoire.

Objectif : prouver la confiance avant de scaler.

---

## 4. Décision recommandée sur les revenus

[HYPOTHESE] Les revenus possibles de Make the Change peuvent venir de :

1. Commission sur soutien producteur.
2. Commission sur achat produit partenaire.
3. Frais de plateforme transparents sur certains dons.
4. Contribution volontaire aux frais.
5. Offre partenaire ou abonnement partenaire plus tard.
6. Offre B2B / RSE plus tard.
7. Abonnement Ambassadeur plus tard.
8. Éditions produits signature plus tard.

[HYPOTHESE] Pour la V1, les sources prioritaires devraient être :

* commission soutien producteur ;
* commission produit partenaire ;
* frais de fonctionnement transparents ;
* pas encore RSE complexe ;
* pas encore marketplace complète.

---

## 5. Décision recommandée sur les dons

[HYPOTHESE] Pour le don pur :

* ne pas prendre de marge cachée ;
* afficher les frais clairement ;
* parler de contribution au projet par défaut ;
* émettre un reçu de contribution, pas un reçu fiscal sauf validation légale ;
* ne pas donner de Credits Impact ;
* éventuellement donner une trace, une nouvelle terrain, une progression narrative ou un lien BioDex si documenté.

[RECOMMANDÉ] Le terme “don” ne devrait être utilisé publiquement que si le bénéficiaire, le document émis et l’éventuel traitement fiscal sont validés. En V1, “contribution” est plus sûr, surtout si Make the Change est une SRL ou si le bénéficiaire n’est pas une institution agréée.

Formulation recommandée :

> Votre contribution soutient ce projet. Le montant net transmis et les frais de fonctionnement sont affichés clairement. Ce reçu n’est pas un reçu fiscal.

---

## 6. Décision recommandée sur le soutien producteur

[HYPOTHESE] Le soutien producteur devrait être le cœur économique le plus clair de Make the Change.

Recommandation :

* commission Make the Change de 10 à 15 % ;
* règle simple en V1 ;
* pas une commission différente pour chaque projet au départ ;
* frais de paiement clairement suivis ;
* montant net producteur visible dans le dashboard partenaire ;
* Credits Impact attribués uniquement ici.

Exemple interne :

* soutien producteur : 100 € ;
* frais paiement : 2,50 € ;
* commission Make the Change : 12 € ;
* montant producteur : 85,50 € ;
* Credits Impact attribués : 100 CI.

---

## 7. Décision recommandée sur la boutique

[HYPOTHESE] La boutique ne doit pas devenir le cœur de Make the Change en V1.

Recommandation :

* sélection limitée ;
* produits fortement liés aux projets ou partenaires ;
* partenaire vendeur officiel en V1 ;
* Make the Change facilitateur ;
* commission claire ;
* pas de stock interne ;
* livraison partenaire ;
* packaging léger co-brandé.

À éviter :

* marketplace massive ;
* produits sans lien avec le vivant ;
* Make the Change vendeur officiel trop tôt ;
* stock important ;
* promesse logistique difficile à tenir.

---

## 8. Décision recommandée sur les Credits Impact

[HYPOTHESE] Règle recommandée :

> 1 € de soutien producteur = 1 Credit Impact reçu.

[RECOMMANDÉ] Cette règle doit rester une règle d’attribution interne, pas une valeur monétaire publique. Le produit peut afficher le nombre de Credits Impact reçus, mais ne doit pas afficher “1 CI = 1 €”.

Mais :

* ne pas afficher que 1 CI = 1 € ;
* ne pas présenter les CI comme une monnaie ;
* ne pas les rendre remboursables ;
* ne pas les rendre transférables ;
* ne pas permettre leur achat direct ;
* ne pas les générer via don, achat produit, mission ou quiz ;
* les utiliser uniquement pour débloquer des avantages partenaires.

Formulation recommandée :

> Les Credits Impact sont des crédits d’usage internes liés à votre soutien producteur. Ils permettent d’accéder à des avantages partenaires dans Make the Change. Ils ne sont pas échangeables contre de l’argent.

Points à valider avant paiement réel :

* moment exact d’attribution : paiement autorisé, capturé ou définitivement confirmé ;
* délai anti-fraude avant utilisation ;
* traitement en cas de remboursement total ou partiel ;
* traitement si les Credits Impact ont déjà été utilisés ;
* impact comptable / TVA éventuel lors de l’émission, de l’utilisation et de l’expiration ;
* financement des avantages : réserve MTC, accord partenaire ou combinaison des deux.

---

## 9. Décision recommandée sur les Graines

[HYPOTHESE] Si les Graines créent trop de confusion avec les Credits Impact, il est préférable de les retirer de la V1 publique.

Alternative recommandée :

* progression pédagogique ;
* badges ;
* parcours complétés ;
* espèces BioDex découvertes ;
* traces d’actions ;
* niveau de compréhension.

Décision proposée :

> V1 sans Graines, ou Graines invisibles côté utilisateur. Les Credits Impact restent la seule valeur d’usage liée à un soutien producteur.

[RECOMMANDÉ] Décision produit nette : V1 publique sans Graines. Les apprentissages, badges et espèces BioDex peuvent exister sans créer une seconde unité de valeur. Les Graines pourront revenir en V2 uniquement si elles ont une fonction non monétaire et immédiatement compréhensible.

---

## 10. Décision recommandée sur les nouvelles terrain

[HYPOTHESE] Les nouvelles terrain doivent devenir un outil de confiance, pas une grosse section lourde.

Recommandation :

* badge discret sur les projets ;
* timeline dans la page projet ;
* notification dans l’app ;
* résumé dans l’historique utilisateur ;
* niveau de preuve affiché clairement.

Trois niveaux recommandés :

1. Nouvelle partenaire : photo/texte envoyé par le partenaire.
2. Suivi documenté : date, source, contexte, personne responsable.
3. Impact vérifié : méthode, source, périmètre, période, limites et niveau de confiance.

---

## 11. Phrase stratégique

> Make the Change doit vendre de la confiance avant de vendre des produits.

Ce qui compte :

* où va l’argent ;
* qui reçoit quoi ;
* ce qui est prouvé ;
* ce qui est estimé ;
* qui livre ;
* qui met à jour le terrain ;
* ce que l’utilisateur reçoit vraiment ;
* ce que Make the Change garde pour fonctionner.
