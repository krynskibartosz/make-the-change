# Documentation Clarus

Ce dossier separe les documents de reflexion initiaux, les decisions consolidees et les futurs plans d'implementation.

## Dossiers

### `00-source-canvases`

Documents initiaux du projet. Ils gardent le contexte large : vision, cahier des charges, zones, backlog, IA et modele de donnees.

Ces fichiers sont utiles pour comprendre l'intention, mais ne doivent pas etre utilises seuls comme spec de developpement.

### `10-v0-planning`

Pack de cadrage V0/V1 :

- produit ;
- patterns web-client ;
- architecture ;
- data mock-first ;
- UX mobile ;
- roadmap.

Ces documents donnent le socle fonctionnel.

### `20-ui-and-references`

References UI et analyse de `apps/web-client` :

- composants/patterns reutilisables ;
- analyse des captures MTC ;
- recommandations pour les ecrans Clarus.

Ces documents guident les composants et le design mobile.

### `30-decisions`

Decisions transverses :

- design system ;
- recherche web ;
- accessibilite ;
- theme ;
- offline ;
- confidentialite.

Ces documents arbitrent les choix avant developpement.
### `40-implementation`

Futur dossier des specs et issues executables.

Il doit contenir les fichiers qui permettent de lancer le developpement sans redecider l'architecture ou l'UX.
