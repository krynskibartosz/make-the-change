# Issues Clarus V0

Ce dossier contient les issues atomiques pour developper Clarus V0 avec des agents coordonnes.

## Ordre recommande

```txt
00-foundation
01-data et 02-ui-primitives en parallele controle
03-screens et 04-add-flow apres contrats stables
05-quality en continu puis final
```

## Regle

Chaque issue doit rester petite, verifiable et sans decision produit majeure.

Si une issue revele une decision ouverte, elle doit etre marquee `blocked` et remontee avant implementation.
